# 温泉管理システム

## 概要  
温泉の情報登録・編集・一覧表示といった基本的なCRUD機能に加え、ユーザーごとのお気に入り登録機能やページング処理、ログイン認証を実装しています。  
画像管理には Cloudinary の外部APIを利用し、サーバー負荷を抑えつつ画像アップロード・表示を実現し、Controller・Service・Repository を分離した構成とし、保守性や拡張性を意識した設計を行いました。  
また、MySQL を用いたデータ管理や、実運用を想定した画面遷移・UI構成にも配慮しています。

## 本番環境  
- 本番URL：http://onsen.white-y0425.com
- インフラ：AWS（EC2 / RDS）  
- デプロイ方法：Docker
